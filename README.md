# .github
TBS Agent — официальная утилита Team BlackSheep для настройки, обновления и обслуживания совместимого FPV-оборудования TBS. Используется для работы с TBS Crossfire, Tracer, видеопередатчиками и другими устройствами экосистемы, управления прошивками, параметрами и подключённым оборудованием.
